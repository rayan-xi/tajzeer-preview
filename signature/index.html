كيف تركّب التوقيع في بريدك


      

        Outlook 365 / Outlook Web (M365)
        
    
          
  1. افتح Outlook Web على outlook.office.com.
    2. 
          
  2. اضغط الترس أعلى اليمين (⚙) ثم عرض جميع إعدادات Outlook.
    3. 
          
  3. من القائمة: البريد ← إنشاء والرد ← التوقيعات.
    4. 
          
  4. اضغط + توقيع جديد، سمّه "تجذير".
    5. 
          
  5. افتح تبويب HTML في المحرر (زر Source).
    6. 
          
  6. الصق كود HTML اللي نسخته من الصفحة.
    7. 
          
  7. خلي التوقيع افتراضي للرسائل الجديدة والردود.
    8. 
          
  8. احفظ ← اختبر برسالة لنفسك.
    9. 
        

      


      

        Outlook Desktop (Windows)
        
    
          
  1. افتح Outlook ← File ← Options ← Mail ← Signatures.
    2. 
          
  2. اضغط New وسمّه "تجذير".
    3. 
          
  3. Outlook Desktop ما يدعم لصق HTML مباشر — استخدم الحل التالي:
    4. 
          
  4. افتح الرابط signature/v2-bilingual.html في Chrome/Edge.
    5. 
          
  5. اختر التوقيع بالمؤشر (Ctrl+A داخل جسم التوقيع) ونسخه (Ctrl+C).
    6. 
          
  6. ارجع إلى محرر التوقيع في Outlook والصق (Ctrl+V).
    7. 
          
  7. احفظ.
    8. 
        

      


      

        Gmail
        
    
          
  1. افتح Gmail واضغط الترس (⚙) ← See all settings.
    2. 
          
  2. مرّر إلى قسم Signature.
    3. 
          
  3. اضغط Create new وسمّه "تجذير".
    4. 
          
  4. افتح signature/v2-bilingual.html في تبويب جديد.
    5. 
          
  5. اختر التوقيع كاملاً (Ctrl+A داخل جسم التوقيع) ونسخ (Ctrl+C).
    6. 
          
  6. الصق في محرر التوقيع في Gmail (Ctrl+V).
    7. 
          
  7. في الأسفل: عيّن التوقيع كافتراضي للرسائل الجديدة والردود.
    8. 
          
  8. Save Changes.
    9. 
        

      


      

        Apple Mail (macOS)
        
    
          
  1. افتح Mail ← Mail ← Preferences ← Signatures.
    2. 
          
  2. اختر حساب البريد على اليسار واضغط + لإضافة توقيع.
    3. 
          
  3. سمّه "تجذير".
    4. 
          
  4. في متصفح Safari، افتح signature/v2-bilingual.html واختر التوقيع كاملاً.
    5. 
          
  5. اسحبه (Drag) وأفلته في محرر التوقيع في Mail.
    6. 
          
  6. اضغط Always match my default message font لإلغاء تفعيلها (مهم).
    7. 
        

      


      

        iPhone / iPad Mail
        
    
          
  1. افتح Safari وادخل الرابط rayan-xi.github.io/tajzeer-preview/signature/v2-bilingual.html.
    2. 
          
  2. اختر التوقيع باللمس المطوّل حتى تنسخه.
    3. 
          
  3. الإعدادات ← Mail ← Signature ← Per Account.
    4. 
          
  4. الصق التوقيع.
    5. 
          
  5. ملاحظة: iOS يفقد بعض التنسيقات — استخدم النسخة Minimal (v3) للحصول على أفضل نتيجة.
    6. 
        

      


      

        Microsoft 365 — إدارة التوقيعات مركزياً لكل الموظفين
        
    
          
  1. يمكن للـ Admin نشر توقيع موحّد على كل الحسابات عبر Exchange Admin Center.
    2. 
          
  2. ادخل admin.exchange.microsoft.com.
    3. 
          
  3. Mail flow ← Rules ← + Add a rule ← Apply disclaimers.
    4. 
          
  4. اختر Apply to all messages أو حدد المرسلين.
    5. 
          
  5. الصق كود HTML للتوقيع في Disclaimer text.
    6. 
          
  6. حدد Fallback action: Wrap.
    7. 
          
  7. احفظ ← فعّل بعد ما تختبر على حساب واحد.
    8.
